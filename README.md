## 🚀 Featured Projects

### 🤟 SignBridge — Bilingual ASL Communication Platform
> Real-time, bidirectional American Sign Language communication platform enabling deaf/mute and hearing individuals to communicate through a standard web browser — no special hardware required.

- 🎯 Transformer-based ASL gesture classification (76% accuracy, 250 signs)
- 🧠 Gemini AI for contextual sentence formation from sign sequences
- 🖐️ Skeleton-based sign animations from pre-extracted keypoints (18MB vs 2.4GB video)
- 🔡 Automatic A–Z fingerspelling fallback for unknown words
- 🌍 6-language input and 5-language audio output
- 🔒 Fully stateless — no accounts, no data retention, complete privacy

**Stack:** React • Flask • PyTorch • MediaPipe • OpenCV • Gemini AI • Tailwind CSS • gTTS

**Roadmap:** ISL Support • React Native App • Cloud Deployment • Expanded Vocabulary
